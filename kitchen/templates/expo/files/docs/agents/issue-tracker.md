# Issue tracker

Issues for this repo live in GitHub Issues on the repo named by `repo` in `.claude/kitchen.json`. Skills that file, read or label tickets (`/to-tickets`, `/triage`, `/find-work`) use this page.

- Read and write issues with the `gh` CLI or the GitHub MCP tools. Never invent an issue number.
- One ticket is one PR's worth of work. A ticket names what changes, how to see it, and what is out of scope.
- Link a parent epic with a task list or sub-issues; link a PR to its ticket with `Closes #<n>`.
- Labels mean what [`triage-labels.md`](triage-labels.md) says, and nothing else.
